# 전북교육지도 로드맵

## 현재 업데이트

탐색 조건 공유, 일반 지표 두 시군 비교, 학교 목록·비교표 CSV, README와 운영 문서, 목록 표시 최적화와 문서 CI를 구현합니다. 검증 결과와 배포 여부는 [검증 기록](UPGRADE_VALIDATION.md), 사용자 변경 사항은 [CHANGELOG](../CHANGELOG.md)를 따릅니다.

## 후속 후보

- 학교 간 비교와 브라우저에 저장하는 관심 학교 목록.
- 시군 지도 연도 전환. 학교별 과거 자료 확보 여부와 집계 단위를 먼저 확인합니다.
- 실제 모바일 기기의 지도·건물 성능 측정과 개선.
- 새 지역 profile 및 새로운 공개 지표. 출처·기준일·결측·재배포 조건을 확인한 자료부터 적용합니다.

후속 후보는 현재 제공 기능이나 확정된 배포 일정이 아닙니다. 로그인·서버 저장·대규모 의존성 교체는 이번 업데이트에 포함하지 않습니다.
