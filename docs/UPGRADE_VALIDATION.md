# 업그레이드 검증 기록

기준 소스: `c7d03f5`. 원자료와 생성 통계는 변경하지 않았습니다. 이 문서는 업그레이드의 배포 전 로컬 검증 결과를 기록합니다. 운영 반영은 GitHub `main`과 Vercel Production을 통해 관리합니다.

## 환경과 확인 범위

- Node.js 22.23.3, npm lockfile 기반 설치, Chromium 153.0.8010.12.
- API 키와 기존 `node_modules`가 없는 별도 소스 복사본에서 `npm ci` 실행. 기존 미추적 `Sparkline.tsx`는 이 복사본에 포함하지 않음.
- 단위·컴포넌트 테스트 833개 통과. 타입 검사·데이터 검증 통과. Lint 오류 0, 기존 경고 2개 유지.
- 프로덕션 빌드의 기본 E2E **73개 통과**(재시도 없음, 13분). 최종 비교표 표시·CSV 범위 설명 수정 후 관련 **6개를 production 빌드에서 재검증해 통과**(58초). 6개는 전체 73개에 포함된 시나리오입니다.
- API 키·`.env.local`·E2E 전용 설정 없이 `npm run dev` 실행 후 실제 브라우저에서 지도·검색·CSV 확인. 외부 지도 요청 0, page error 0. 건물 API는 키 미설정 시 예상대로 503 반환.
- 실제 VWorld API·운영 사이트 검증은 수동 워크플로로 분리. 이번 기본 회귀 검사는 fixture를 사용합니다.

## 주요 검증 시나리오

- 학교 검색어·학교급 공유, 새 페이지에서 복원, 잘못된 학교급의 기본값 처리, 클립보드 성공·권한 거절 경로.
- 전체 학교 목록 중 50개만 DOM에 표시하고 추가 표시 가능. CSV는 아직 화면에 펼치지 않은 검색 결과도 모두 저장.
- 일반 지표 18개 및 교육문제별 두 지역 비교. 비교 상태를 유지한 지표 전환과 새로고침.
- 표시 값과 CSV 값의 일치, 백분율 차이의 %p, 0과 결측 구분, 범주형 지정 상태 차이 계산 제외.
- CSV의 한글·쉼표·따옴표·줄바꿈, 텍스트 수식 방지, 숫자형 음수 보존, 학교별 선택 지표 포함.
- 시계열의 공통 축, 누락된 연도와 null 구간의 단절, 단일 연도에서 추이 미생성.
- 1440·1280·1024·390px 전환에서 헤더와 지도 동작 버튼의 비겹침. 360·390px 비교·공유 조작, 가로 넘침, 포커스 유지와 Escape 닫기.
- 기존 WebGL 미지원·컨텍스트 손실, 데이터 실패 후 재시도, 건물 실패·복구, URL 호환성은 전체 E2E에 포함.

## 성능

[변경 전 기록](performance/before.json)과 [변경 후 기록](performance/after.json)은 같은 개발 서버 방식, 동일 Chromium, 동작 축소 설정에서 뷰포트별 새 컨텍스트 3회 측정입니다. 변경 전 수치는 Playwright가 결과 폴더를 교체하기 전에 출력된 원래 실행 로그에서 보존했습니다.

최종 측정 중앙값(각 3회, 단위 ms):

| 화면 | 지도 준비 전 → 후 | 검색 전 → 후 | 지표 URL 전 → 후 | 첫 건물 요청 전 → 후 | 건물 렌더 후 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 1440×900 | 4,465 → 6,122 | 221 → 868 | 233 → 459 | 1,512 → 2,333 | 3,433 |
| 390×844 | 3,955 → 3,888 | 139 → 174 | 146 → 181 | 1,482 → 1,566 | 2,080 |

초기 데이터 요청은 전후 모두 76회, 디코딩 본문 합계 1,039,184바이트였습니다. 개발 모드 중복 로딩을 포함한 값이며 압축 전 바이트 수입니다.

이 표에서 데스크톱 측정 지연은 증가했습니다. 이 환경의 결과로 성능 개선을 주장하지 않습니다. 실기기에서의 추가 측정과 원인 분리는 후속 과제로 남깁니다. 변경 전의 건물 응답은 빈 fixture였고 최종 측정에는 작은 건물 도형을 넣었습니다. 따라서 건물 렌더 시간은 최종 버전에서만 기록한 값이며 전후 비교하지 않습니다.

지도 준비 표시·검색 결과 반영·지표 URL 변경·첫 근접 건물 요청을 측정합니다. 건물 렌더는 fixture 도형 레이어의 로드 후 deck.gl 렌더 콜백까지의 시간이며 실제 외부 데이터 서비스나 물리 GPU 표시 완료 시간은 아닙니다.

렌더러는 SwiftShader 소프트웨어 GPU입니다. 개발 서버의 컴파일·다른 시스템 작업 영향을 포함하고 표본도 적으므로 속도 향상이나 실제 휴대전화 FPS를 단정하지 않습니다. 파일 요청량은 개발 모드에서 초기 로딩이 중복 실행되는 경우까지 포함합니다.

구조적으로 확인한 변경은 기본 자료와 manifest 검증 이후 지표 요청의 중첩, 최초 학교 목록 DOM 50개 제한입니다. 느린 경계 응답이 지표 요청 시작을 막지 않는다는 단위 테스트를 포함합니다.
